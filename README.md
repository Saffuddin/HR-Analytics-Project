# HR Analytics Project (PRDA-03)

## Project overview
Analysis of 22,214 employee records using the supplied CSV dataset.

## Key KPIs
- Total employees: 22,214
- Remote workers: 24.75% (5,499)
- Headquarters workers: 75.25% (16,715)
- Average age: 38.43 years

## Deliverables
- `Analysis_Report.pdf` – KPI report, charts, insights and recommendations
- `HR_Analytics_Presentation.pptx` – presentation
- `Dashboard_Screenshots/` – generated chart images
- `Untitled(3).csv` – source dataset (include only if permitted by your institute)

## Tools
Python, pandas, matplotlib, reportlab and python-pptx were used to prepare the report and visuals.
The charts are prepared from the supplied CSV. If your instructor specifically requires Tableau/Power BI dashboard screenshots, export screenshots from your own Tableau/Power BI workbook and add them to `Dashboard_Screenshots/`.

## Data note
The assignment brief states 13 columns; the supplied CSV has 14 columns including `gender`. The `termdate` field includes future dates up to 2041, so turnover and active-employee counts were not inferred.
